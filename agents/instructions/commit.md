# Commit 约定

- 标题格式：`<type>(<scope>): <gitmoji> <subject>`；scope 不明确时省略括号。
- subject 用英文祈使句，小写开头，不加句号。
- type 与 gitmoji 对应：feat `:sparkles:`、fix `:bug:`、docs `:memo:`、style `:art:`、refactor `:recycle:`、perf `:zap:`、test `:white_check_mark:`、build `:package:`、ci `:construction_worker:`、chore `:wrench:`。
- 删除用 `:fire:`，移动文件用 `:truck:`，安全修复用 `:lock:`。
- 简单改动只写标题；非平凡改动空一行后加简短的 bullet body。
- 只描述已暂存的内容。
